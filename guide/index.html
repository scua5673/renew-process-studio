팀이 함께 쓰는 전술 스튜디오 — 작전판·훈련 설계·일정·선수단·개인 성장(IDP)·노트가 한 곳에.
이 책은 코치가 쓰는 법(1부), 선수가 쓰는 법(2부), 팀이 함께 쓰는 법(3부)으로 나뉩니다.

이 책을 읽는 법

  • 코치라면 — 0부(시작하기)를 훑고 1부를 처음부터 읽으세요. 작전판 → 훈련 설계 → 일정 순서가 실제 업무 흐름과 같습니다.
  • 선수라면 — 0부에서 로그인·설치만 확인하고 바로 2부(IDP)로 가세요. 로그인·팀 없이도 전부 쓸 수 있습니다.
  • 팀을 운영한다면 — 3부의 워크스페이스 장을 먼저 읽고 초대 코드를 만드세요. 나머지는 각자 자기 편을 읽으면 됩니다.
  • 본문의 [대괄호]는 화면의 실제 버튼 이름입니다. 키보드 표기는 단축키입니다.

0-1. 설치 없이 링크로

PROCESS STUDIO는 웹앱입니다. 주소만 열면 어느 기기에서든 바로 시작됩니다. 아이패드·데스크톱에 최적화되어 있고, 폰에서는 하단 탭바가 있는 모바일 화면으로 자동 전환됩니다.

0-2. 데이터는 어디에 저장되나

모든 데이터는 먼저 이 기기(브라우저)에 저장됩니다. 인터넷이 없어도 작전판·일정·노트를 열고 편집할 수 있고, 연결되면 자동으로 동기화됩니다.

  • 비로그인 + 미설치 상태로 오래 안 열면 브라우저가 저장소를 비울 수 있습니다. 데이터가 쌓이면 "지금은 이 기기에만 저장돼요" 배너가 뜨니, [안전하게 저장]을 눌러 설치하거나 로그인하세요. 지금까지 쓴 내용은 로그인해도 그대로 넘어갑니다.
  • 저장 공간이 가득 차면 빨간 경고가 뜹니다. 먼저 설정 → 백업 → 내보내기를 하고, 저장 공간 → 안전 정리를 누르세요. IndexedDB에 같은 내용이 확인된 중복 사본만 정리하며 실제 기록은 삭제하지 않습니다.
  • 팀 워크스페이스에서도 새 보관함 항목은 먼저 내 기기에 저장됩니다. 팀원에게 보여줄 때만 카드의 더보기 → 팀 스페이스에 공유를 누르세요.

0-3. 로그인과 동기화

상단 오른쪽 [로그인]을 누르면 계정 패널이 열립니다.

  • [카카오로 계속] / [Google로 계속] — 둘 중 편한 것으로.
  • 로그인하면 작전판·보관함·팀 자료가 여러 기기에서 자동 동기화됩니다. 동기화는 앱을 열 때, 3분마다, 앱을 나갔다 돌아올 때, 오프라인에서 온라인으로 복귀할 때, 편집 후 4초 뒤에 자동으로 일어납니다. 급하면 계정 패널의 [지금 동기화].
  • 로그인 도중 시간이 지나거나 다른 탭에서 먼저 완료되면 “로그인 연결 시간이 지났어요” 안내가 뜹니다. 작업은 이 기기에 그대로 있으니 Google 또는 카카오 로그인을 다시 누르면 됩니다.
  • [표시 이름 설정] — 작전판·보관함에 "만든 사람"으로 표시될 이름입니다.

1장 작전판 — 전술을 그리는 곳

1-1. 첫 5분: 포메이션으로 시작

빈 작전판에는 "포메이션으로 시작" 카드가 떠 있습니다.

  1. 우리 팀에서 4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 3-4-3 중 선택. 유소년이라면 8인제(2-3-2, 3-3-1, 3-2-2, 2-4-1)도 있습니다.
  2. 상대 팀도 필요하면 선택(기본 '없음'). 각 팀 이름 옆 색점을 누르면 팀 색을 바꿉니다.
  3. [배치] — 선수들이 포메이션대로 올라옵니다.

나중에 포메이션을 바꾸려면 [더보기 ▾] → 포메이션에서 우리/상대를 각각 선택하세요(백4 5종, 백3 3종, 8인제 4종).

6-2. 선수 관리

6-3. 스카우트 — 포지션 적합 비교

6-4. 기준 설정 — 포지션별 목표 레벨

포지션마다 "이 자리에 원하는 수준"을 속성별 1~5로 정의합니다. 이것이 선수 평가·스카우트 비교의 잣대가 됩니다.

  • ★ 핵심 속성 토글, 속성 이름 수정, ▲▼ 순서, [표준 순서로 정렬], [기본값(11슬롯)].
  • 팀 스타일 위저드(점유/역습/압박)로 전 포지션 역할을 일괄 적용할 수도 있습니다.

6-5. 평가 항목 — 우리 팀의 어휘

기본 5개 카테고리(전술/기술/체력/심리/태도)의 항목을 팀 언어로 고칩니다 — 카테고리 추가(예: 골키핑), 속성 추가·이름 수정·삭제. 여기서 바꾼 어휘가 선수 입력·기준 설정·선수의 IDP 셀프 평가에까지 전부 반영됩니다.

6-6. 코치 이미지노트

팀 탭의 이미지노트는 코치의 경기 전 리허설 노트입니다 — 게임플랜 / 예상 상황과 대응 / 벤치에서 볼 것 / 심리기술 전략 / 칭찬 및 각오. 경기마다 한 장씩 쌓입니다(개인 데이터, 팀 동기화 안 함).

7장 게임모델과 공용어 — 팀의 언어

7-1. 게임모델 — 우리 축구의 설계도

  • 팀 정체성 — 우리 팀을 한 문장으로.
  • 스타일로 시작 — [점유율 축구] [역습 중심] [강한 압박] 중 고르면 4국면이 실제 원칙으로 채워집니다. [빈 템플릿]은 골격만.
  • 4국면 — 공격 조직(빌드업/전진·전개/침투·마무리), 수비 조직(전방 압박/미드 블록/로우 블록), 공→수 전환(역압박/후퇴·재정비), 수→공 전환(빠른 역습/점유 안정화). 국면·단계·원칙 모두 추가·수정·순서 변경·삭제가 자유롭습니다.
  • 원칙 칩 — 자주 쓰는 원칙을 탭 한 번으로 추가(타이핑 없이). 트리거(신호) 체크리스트("예: 상대 백패스")도 국면마다.
  • 작전판 첨부 — 원칙 옆에 작전판 장면 스냅샷을 붙이고 [▶ 보기]로 엽니다.
  • [PDF로 내보내기] — 전 국면을 문서로. 미입력 원칙은 인쇄에서 자동 생략.

게임모델의 국면은 일정의 국면 배분 게이지, 훈련의 원칙 태그와 연결됩니다 — 설계도가 훈련량으로 검증되는 구조입니다.

7-2. 공용어 — 같은 말로 부르기

팀이 같은 상황을 같은 말로 부르게 하는 사전입니다. 3계층:

  • 신호어 — 경기 중 1~2초 안에 외치고 즉시 움직이는 말(영어=실제 외침, 한글=뜻).
  • 행동 용어 — 훈련·영상 분석에서 같은 이름으로 부르는 동작 단위.
  • 구조 개념 — UEFA·FIFA 공통 경기 원칙·4국면·구역 등 분석·토의 언어.

[＋ 용어 추가]로 직접 쌓거나, [세트 불러오기]로 시작하세요: 핵심 스타터(~15개) · 국제 표준 UEFA·FIFA(~57개) · PROCESS+국제표준 통합(추천) · PROCESS 용어. 병합 시 중복은 건너뜁니다. 검색은 한글·영어·행동 기준 전체에서.

2부 선수 편 — IDP(개인 성장 계획)

상단 내비 [IDP]. 선수가 스스로 채우는 공간입니다. 로그인·팀 없이도 전부 쓸 수 있고, 팀에 합류하면 평가 항목이 팀 기준으로 바뀌고 코치가 내 IDP를 읽기 전용으로 볼 수 있습니다.

8장 시작 3단계

처음 열면 3단계 온보딩이 안내합니다: ① 프로필 만들기 → ② 나를 평가하기 → ③ 이번 달 목표 만들기.

8-1. 프로필

사진, 이름·생년월일·소속팀·포지션·주발, 서브 포지션, 신체(키·몸무게·혈액형·MBTI), 축구 경력, 주요 성과, 하이라이트 영상 링크까지 — 나의 축구 이력서입니다.

8-2. 셀프 평가 — 내가 보는 나

전술·기술·체력·심리·태도 카테고리를 펼쳐 항목마다 1~5를 누릅니다. 한 카테고리를 끝내면 접히고 다음으로.

  • 능력 레이더 — 내 점수(실선)와 코치 평가(점선)를 겹쳐 봅니다. 코치 평가가 있으면 항목 옆에 파란 숫자로 병기.
  • 성장선 — 평가를 저장할 때마다 그 날의 전체 평균이 이력으로 쌓여 변화가 보입니다.

8-3. 이번 달 목표

[＋ 이번 달 목표 만들기] — 보완할 속성을 1~2개 고르고, 내 훈련과 연결하고, 주당 횟수·주 수를 정합니다.

  • 목표 카드에 히어로 숫자(실행 N/목표 M회)와 진행바, 시간 경과 눈금이 표시됩니다. 실행이 시간보다 뒤처지면 경고가 떠요.
  • 연결한 훈련의 요일이면 "오늘은 하는 날"이 표시되고, 일정에서 완료를 체크하면 진행률이 올라갑니다.
  • 4주가 끝나면 [리뷰하고 마무리] — 결과(↑늘었어 / →그대로 / ↓아쉬워)가 "지난 목표"에 쌓입니다.
  • 시즌 시간표 — [＋ 시즌 시작]으로 1년을 걸어두면 경과 %와 남은 날이 늘 보입니다.

9장 개인 훈련과 일지

9-1. 내 훈련 만들기

[＋ 훈련 만들기] — 제목·목표, 요일 칩(주간 루틴), 운동 목록(이름·세트·시간), 작전판 그림까지. 카드를 탭하면 언제든 수정.

9-2. 일정에 기록하기

IDP의 일정 탭은 나의 훈련 달력입니다(월간/주간/일간).

  • 날짜 탭 → 퀵 기록: 이 날은 [팀훈련/경기/휴식] + 개인운동 토글, 내 훈련 ✓ 완료 체크, 강도(RPE 0~10) 슬라이더, 몸무게(kg), 자유 기록.
  • 주간 뷰에서는 유형 배지를 탭할 때마다 없음→팀훈련→경기→휴식으로 순환합니다.
  • 연속으로 기록하면 스트릭(🔥) 배지가 붙고, 훈련강도 막대 + 몸무게 라인 그래프로 몸 상태 추이를 봅니다.

12장 팀 워크스페이스

12-1. 팀 만들기와 초대

  1. 계정 패널(로그인 후) → [＋ 팀 만들기] — 팀 이름을 정하면 그 팀 전용 보관함·일정·팀명단이 생깁니다.

  3. 팀원은 먼저 팀에서 구분할 이름 또는 아이디를 반드시 입력하고, [코드로 합류]에 초대 코드를 넣으면 선수 역할로 합류합니다.
  4. 코칭스태프나 임원으로 바꿔야 하는 팀원은 합류 후 관리자가 [권한 관리]에서 역할을 변경합니다.
  5. 코드가 새면 [새 코드 생성] — 기존 코드는 즉시 무효화됩니다.

개인 공간은 따로입니다. 계정 패널의 워크스페이스 목록에서 내 워크스페이스와 팀들을 오가며, 개인 데이터와 팀 데이터는 섞이지 않습니다. 개인 노트·IDP는 워크스페이스에 종속되지 않고 나를 따라다닙니다.

역할은 관리자(owner/admin) / 코칭스태프 / 선수 3가지, 편집 구역은 6개(작전판·보관함 / 일정 / 팀 / 게임모델 / 공용어 / 노트)입니다.

  • 권한이 없는 구역은 노란 자물쇠 배너("편집 권한이 없어 보기 전용입니다")가 뜨고 편집 버튼이 숨겨지며 저장되지 않습니다.
  • [권한 관리]에서 멤버별 역할·구역과 "새로 합류하는 팀원 기본 역할"을 정합니다. 선수 멤버는 팀 탭의 선수와 연결할 수 있습니다.
  • 선수는 권한과 무관하게 자기 IDP는 항상 자유롭게 쓰고, 코치는 선수 선택 메뉴로 각 선수의 IDP를 읽기 전용으로 열람합니다.
