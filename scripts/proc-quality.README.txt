공식 커뮤니티 훈련 편집 · 2026-10-24

범위: 레터 02–46호 / 45세션 / 135훈련. 공개 코치 자료 게시물은 별도 자료다.
기준 원문: proc-practices-source.json의 기존 공식 method/coaching. 원문은 수정하지 않고 보존한다.
훈련별 보완 원고: proc-coaching.tsv (관찰 / 질문 / 한 가지 조정 / 재확인 / 재개·교대).
편집·도식 처리: proc-quality.mjs. 실제 움직임 목록은 기존 proc-scenes/NN.mjs에 있다.

새로운 훈련 내용·책 출처를 만들어 붙이지 않는다. 목적·인원·공간·득점 규칙을 원문과 대조한다.
재개 규칙은 기존 원문을 우선한다. 없는 운영 지침과 개입 시나리오는 '운영 보완'으로 표시한다.
원문 오류 수정은 corrected()에 모은다. 특히 구역 인원, GK를 뺀 필드 인원, 기록자, 훈련 수정 규칙을 구분한다.
선수 주도 훈련의 질문은 휴식 때 한다. 복귀·회복 훈련은 원문의 담당자 제한과 구간 목적을 유지한다.
The Drills App의 공개 라이브러리·상세 페이지는 목적/진행/코칭/발전/조건을 구분하는 설명 구조 참고다.
참고 주소: https://thedrillsapp.com/library
상세 구조 확인: https://thedrillsapp.com/football-drills/practice/05288bc1-05d5-4aba-baba-35c4f209d60c/brugge-3rd-man-finishing
위 사이트의 훈련 본문이나 도식을 복사하지 않았다.

다시 만들기:
  node scripts/proc-scenes.mjs {02..46}
  node --test tests/proc-quality.test.cjs tests/proc-scenes-3019.test.cjs tests/proc-snapshot-3003.test.cjs
  node tests/browser/community-quality.mjs
브라우저 실행에는 기존 PS_PLAYWRIGHT_MODULE / PS_CHROME_PATH 설정을 쓴다.
PS_WRITE_QUALITY_THUMBS=1이면 135개 그림을 네이티브 boardThumbSVG로 다시 만든다.
PS_QUALITY_OUTPUT으로 점검 이미지·보고서 저장 폴더를 지정할 수 있다.

SVG는 proc-snapshot.mjs의 svgProblem으로 검사한다. 활성 요소·외부 주소를 넣지 않는다.
골대는 입구를 골라인에 고정하고 그물을 밖에 둔다. 원문에 없는 폭은 도식용 예시임을 설명한다.
슈팅 장면의 득점 예시만 골 입구·공 크기에 맞춰 조정하며 선방·빗나감 장면을 득점으로 바꾸지 않는다.
기록 도식의 흰색/주황 점은 이전 슛의 예시다. 진행 중 운동장에 놓아 두는 장비로 그리지 않는다.

공식 카드 대표 snap/frames는 첫 훈련과 같아야 한다. index.json의 own:1과 SHA1 rev를 함께 갱신한다.
이 경로의 변경은 앱의 커뮤니티 '프로세스' 칸에 적용된다. 운영 데이터베이스 수정은 필요 없다.
기존에 사용자가 보관함에 담아 편집한 카드는 자동으로 덮지 않는다. 필요하면 '한 장 더 담기'를 쓴다.
