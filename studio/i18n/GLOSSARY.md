# PROCESS STUDIO — English glossary (용어집)

영어 사전(`studio/i18n/en-<영역>.js`)을 쓸 때 따르는 말이다. 같은 한국어는 어디서나 같은 영어로 — 새 말을 정하면 여기에 먼저 적는다.
영국식 축구 영어를 쓴다(pitch · kit · colour · match · squad · fixture). 문장은 짧게, 단추는 동사로(«Save», «Try again»).

## 번역하지 않는 것

- **브랜드**: «PROCESS STUDIO» · «Process Letter»(프로세스 레터) 의 로고 글자, «Kakao» · «Google».
- **사용자 내용**: 선수 이름 · 팀 이름 · 조 이름(A팀 · B팀) · 메모 · 훈련 이름 · 보관함 자료 제목 · 직접 쓴 포지션 약칭. 사전에는 고정 문구만 넣는다 — 예시로 박힌 «프로세스FC» · «김철수 코치» 는 `e.g. Process FC` 처럼 예시 문장(placeholder)일 때만 옮긴다.
- **입력해야 하는 말**: 사용자가 그대로 쳐야 하는 낱말은 코드가 받는 값과 맞춘다(계정 삭제 확인은 «삭제» 또는 «delete» 둘 다 받는다).
- **판 소개 글**(release-notes.js) · **학습 교재**(learn-*.js) · 커뮤니티 글은 내용(content)이라 아직 한국어다.
- **파일 이름 · 키 · 오류 코드**(`cs_lang`, `ps_kv`, `IndexedDB`).

## 사전 쓰는 법

- `D`: 원문 그대로(공백 · 줄바꿈은 한 칸으로) → 영어. 한 글 노드 · 한 속성값이 한 줄이다.
- `T`: 값이 끼는 글은 `{}` 틀로 — `"{}분 전":"{} min ago"`. 차례가 바뀌면 `{1}` `{2}`. 구멍에 들어온 말이 사전에 있으면 그것도 바뀐다.
- `C`: 같은 원문이 자리마다 달라야 할 때 `"CSS 선택자":{"원문":"영어"}`.
- 한국어는 문장을 태그로 쪼개 그리는 곳이 많다(«아래 **지금 설치** 를 누르면»). 조각마다 따로 번역되므로, 이어 읽어도 · 혼자 읽어도 어색하지 않게 쓴다.
- 길이: 왼쪽 메뉴 · 폰 하단 메뉴는 한 낱말(12자 안팎). 넘치면 `tests/browser/i18n-english-shell.mjs` 가 잡는다.
- 무엇이 남았나: `node scripts/i18n-coverage.mjs --missing <영역>` · 기준 다시 적기: `--write-baseline`.
