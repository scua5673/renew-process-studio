양식 — 펜으로 쓰는 1장 폼

펜으로 기입하는 1장짜리 폼이에요. 누르면 미리보기가 뜨고, 인쇄하거나 PDF로 저장할 수 있어요.
✍︎ 기입한 내용이 채워진 출력은 일정·팀 탭 안의 출력 버튼에서 — 입력한 일정·라인업·시즌 리포트가 그대로 폼에 들어갑니다.

사용법 안내

작전판 · 보관함 · 일정 · 팀 · 노트 · 메모 · 양식 — 일곱 가지 도구가 하나로. 설치 없이 브라우저에서 바로 쓰고, 폰·태블릿·PC 어디서나 열립니다.
시작하기작전판보관함일정팀노트·메모양식공유·백업

0시작하기

상단에 탭 7개와 버튼 2개가 전부입니다.

  • 작전판 · 보관함 · 일정 · 팀 · 노트 · 메모 · 양식 — 도구 전환 탭
  • 공유 — 지금 보고 있는 화면(작전판·드릴 등)을 링크로 복사
  • ⚙︎ 설정 — 테마(라이트/다크) · 언어 6개(한국어·日本語·English·中文·Español·Português) · 백업 내려받기/복원 · 사용법 · build 표시
폰에서 자주 쓴다면 브라우저 메뉴의 "홈 화면에 추가"를 해두세요. 앱처럼 열립니다.
데이터는 전부 이 기기 브라우저에 저장됩니다 — 서버로 전송되지 않아요. 기기를 바꾸거나 브라우저 데이터를 지우면 사라지니, ⚙︎ → 백업 내려받기를 습관으로 해주세요.

1작전판

전술을 그리고, 움직임을 애니메이션으로 만들고, 파일로 내보냅니다.

  • 그리기 — 토큰·화살표·도형·텍스트로 전술 표현, 운동장은 1~3개까지
  • 유니폼 — 팀 칩을 한 번 더 탭하면 색·패턴 변경
  • 경기 모드 — 전광판·기록, 미팅 모드 — 키노트처럼 선수단 앞 발표
  • 애니메이션 — 장면을 추가하며 토큰을 옮기고 이어서 재생. 이동은 선택한 장면의 아이콘 속도, 유지는 모든 장면의 일정한 대기 시간을 조절합니다
  • 내보내기 — PNG · 영상 · PPT

2보관함

훈련 드릴을 만들고, 작전판·드릴·미팅을 한곳에 모아둡니다.

  • 훈련 만들기 — 그림을 만든 뒤 훈련 메모를 설계 → 운영 → 학습 리뷰 순서로 작성
  • 빠른 메모 — 훈련 중 떠오른 내용은 먼저 짧게 기록하고 나중에 정리
  • 설계 — 학습 목적·성공 기준·선수 과제와 4Ds(Direction · Definition · Decisions · Difference) 점검
  • 운영 — Organisation · Explanation · Variations · Coaching Points와 안전·재미·포용성 확인
  • 학습 리뷰 — 선수의 말·학습의 증거·기억할 한 문장·코치 성찰·다음 세션 연결
  • 폴더·태그·즐겨찾기로 정리
  • 항목 카드에서 제목변경·복제·PDF
  • 발표 모드 — 저장한 항목을 그대로 띄워 미팅 진행
  • 드릴 팩(JSON) 내보내기/가져오기 — 드릴 묶음을 파일로 교환
처음에는 전부 채우지 않아도 됩니다. 빠른 메모와 학습 목적만 기록하고, 훈련이 끝난 뒤 학습 리뷰를 보완하면 됩니다. 저장한 항목은 보관함·커뮤니티 공유·PDF에도 함께 유지됩니다.

3일정

경기일(MD)을 기준으로 주간·월간 훈련을 계획합니다.

  • 주간 보드 — 경기일을 잡으면 각 날에 MD(경기까지 며칠)가 붙습니다
  • 세션 시트 — 블록 단위로 훈련 설계
  • 월간 달력과 그래프(부하 리뷰)
  • 지난주 복사 · MD 리듬 채우기로 빈 주를 빠르게
  • PDF 출력 지원

4팀

선수단·스카우트·게임모델을 한 탭에서 관리합니다.

  • 선수단 — 포메이션·선수 프로필·평가
  • 스카우트 — 관찰 대상 선수 관리
  • 기준 설정 — 우리 팀의 평가 기준 정의
  • 게임모델 — 국면·단계별 플레이 원칙 정리
  • 매치데이 명단 출력

5노트·메모

필기는 노트, 짧은 기록은 메모.

  • 노트 — 펜슬 필기, 배경 양식 선택
  • PDF를 불러와 그 위에 필기할 수 있어요
  • 메모 — 빠른 텍스트 메모

6양식

펜으로 쓰는 1장짜리 인쇄 폼 모음입니다.

  • 월간·주간·일간·매치데이 + 스카우트·분석 폼들
  • 누르면 미리보기 → 인쇄 / PDF 저장
  • 잉크 절약 모드 지원

7공유·백업

링크로 전달하고, 데이터는 직접 지킵니다.

  • 상단 공유 — 현재 화면(작전판·드릴 등)을 링크로, 받는 사람은 설치 없이 열람
  • ⚙︎ → ⤓ 모든 데이터를 JSON 한 파일로 내려받기
  • ⚙︎ → ⤒ 백업 파일 선택 → 불러오기 (기존 데이터에 합쳐집니다 · 항목 삭제 없음)
  • 기기를 바꾸기 전엔 반드시 백업 — 데이터는 서버가 아니라 이 기기 브라우저에만 있습니다

使い方ガイド

戦術ボード · 保管庫 · スケジュール · チーム · ノート · メモ · フォーム — 7つのツールをひとつに。インストール不要、スマホ・タブレット・PCのブラウザですぐ使えます。
はじめに戦術ボード保管庫スケジュールチームノート・メモフォーム共有・バックアップ

0はじめに

上部にあるのはタブ7つとボタン2つだけです。

  • 戦術ボード · 保管庫 · スケジュール · チーム · ノート · メモ · フォーム — ツール切り替えタブ
  • 共有 — 今見ている画面（ボード・ドリルなど）をリンクとしてコピー
  • ⚙︎ 設定 — テーマ（ライト/ダーク）· 言語6つ（한국어·日本語·English·中文·Español·Português）· バックアップのダウンロード/復元 · 使い方 · build表示
スマホでよく使うなら、ブラウザメニューの「ホーム画面に追加」を。アプリのように開けます。
データはすべてこの端末のブラウザに保存されます — サーバーには送信されません。端末を替えたりブラウザデータを消すと失われるため、⚙︎ → バックアップのダウンロードを習慣にしてください。

1戦術ボード

戦術を描き、動きをアニメーションにして、ファイルに書き出します。

  • 描く — トークン・矢印・図形・テキストで戦術を表現、ピッチは1〜3面まで
  • ユニフォーム — チームチップをもう一度タップすると色・柄を変更
  • 試合モード — スコアボード・記録、ミーティングモード — キーノートのようにチームの前で発表
  • アニメーション — 場面を追加して再生。移動は選択場面のアイコン速度、維持は全場面共通の待ち時間です
  • 書き出し — PNG · 動画 · PPT

2保管庫

トレーニングドリルを作り、ボード・ドリル・ミーティングをひとつにまとめます。

  • トレーニング作成 — 図を作り、設計 → 運営 → 学習レビューの順で記録
  • クイックメモ — 現場で気づいたことを先に短く残す
  • 設計 — 学習目的・成功基準・選手タスクと4Ds（Direction · Definition · Decisions · Difference）
  • 運営 — Organisation · Explanation · Variations · Coaching Pointsと安全・楽しさ・包摂性を確認
  • 学習レビュー — 選手の言葉・学習の証拠・要約・コーチの振り返り・次回への接続
  • フォルダ・タグ・お気に入りで整理
  • 項目カードから名前変更・複製・PDF
  • 発表モード — 保存した項目をそのまま映してミーティング
  • ドリルパック（JSON）の書き出し/読み込み — ドリルのセットをファイルで交換

3スケジュール

試合日（MD）を基準に週間・月間トレーニングを計画します。

  • 週間ボード — 試合日を決めると各日にMD（試合まで何日）が付きます
  • セッションシート — ブロック単位でトレーニングを設計
  • 月間カレンダーとグラフ（負荷レビュー）
  • 先週コピー · MDリズム入力で空の週を素早く
  • PDF出力対応

4チーム

スカッド・スカウト・ゲームモデルをひとつのタブで管理します。

  • スカッド — フォーメーション・選手プロフィール・評価
  • スカウト — 観察対象の選手を管理
  • 基準設定 — チームの評価基準を定義
  • ゲームモデル — 局面・段階ごとのプレー原則を整理
  • マッチデーの名簿を出力

5ノート・メモ

手書きはノート、短い記録はメモ。

  • ノート — ペンシル手書き、背景フォームを選択
  • PDFを読み込んで、その上に書き込めます
  • メモ — 素早いテキストメモ

6フォーム

ペンで書き込む1枚ものの印刷フォーム集です。

  • 月間・週間・日間・マッチデー + スカウト・分析フォーム
  • 押すとプレビュー → 印刷 / PDF保存
  • インク節約モード対応

7共有・バックアップ

リンクで届け、データは自分で守ります。

  • 上部の共有 — 今の画面（ボード・ドリルなど）をリンクに。受け取った人はインストールなしで閲覧
  • ⚙︎ → ⤓ 全データをJSONファイルひとつでダウンロード
  • ⚙︎ → ⤒ バックアップファイルを選択 → 復元（現在のデータを上書きします）
  • 端末を替える前は必ずバックアップ — データはサーバーではなくこの端末のブラウザだけにあります

How to use

Tactics board · Library · Schedule · Team · Notes · Memo · Forms — seven tools in one. No install needed; runs in the browser on phone, tablet and PC.
Getting startedTactics boardLibraryScheduleTeamNotes & MemoFormsSharing & Backup

0Getting started

The header is just seven tabs and two buttons.

  • Tactics board · Library · Schedule · Team · Notes · Memo · Forms — tool tabs
  • Share — copies what you're looking at (board, drill, …) as a link
  • ⚙︎ Settings — theme (light/dark) · 6 languages (한국어·日本語·English·中文·Español·Português) · backup download/restore · guide · build tag
If you use it on your phone, tap "Add to Home Screen" in the browser menu — it opens like an app.
All data lives in this device's browser — nothing is sent to a server. It's lost if you switch devices or clear browser data, so make ⚙︎ → backup download a habit.

1Tactics board

Draw tactics, animate the movement, export to files.

  • Draw — tokens, arrows, shapes and text; use 1–3 pitches
  • Kits — tap a team chip again to change its colour and pattern
  • Match mode — scoreboard & log; Meeting mode — present keynote-style to the squad
  • Animation — add scenes and play them as one sequence. Move sets icon speed for the selected scene; Hold keeps the pause between scenes consistent
  • Export — PNG · video · PPT

2Library

Build training drills and keep boards, drills and meetings in one place.

  • Create training — build the diagram, then use Design → Delivery → Learning review
  • Quick memo — capture observations on the pitch and organise them later
  • Design — learning purpose, success criteria, player task and the 4Ds (Direction · Definition · Decisions · Difference)
  • Delivery — Organisation · Explanation · Variations · Coaching Points, plus safety, fun and inclusion
  • Learning review — player voice, evidence of learning, one-line summary, coach reflection and the next session
  • Organise with folders, tags and favourites
  • Rename, duplicate or PDF any item from its card
  • Presentation mode — run a meeting straight from a saved item
  • Drill pack (JSON) export/import — swap drill sets as files

3Schedule

Plan weekly and monthly training around matchday (MD).

  • Weekly board — set a match and every day gets an MD (days to match) tag
  • Session sheet — design sessions block by block
  • Monthly calendar and Graph (load review)
  • Copy last week · fill the MD rhythm to build an empty week fast
  • Exports to PDF

4Team

Squad, scouting and your game model in one tab.

  • Squad — formation, player profiles, ratings
  • Scout — track the players you're watching
  • Criteria — define your team's evaluation standards
  • Game Model — organise play principles by phase and stage
  • Print the match day squad list

5Notes & Memo

Handwriting in Notes, quick text in Memo.

  • Notes — pencil handwriting with background templates
  • Import a PDF and write on top of it
  • Memo — quick text notes

6Forms

One-page printable forms you fill in by pen.

  • Monthly, weekly, daily and match day forms plus scouting & analysis forms
  • Tap one for a preview → Print / Save PDF
  • Ink-saver mode included

7Sharing & Backup

Deliver with a link; guard your data yourself.

  • Header Share — turns the current view (board, drill, …) into a link; recipients open it without installing
  • ⚙︎ → ⤓ downloads all data as a single JSON file
  • ⚙︎ → ⤒ pick a backup file → import (merges into current data · nothing deleted)
  • Always back up before switching devices — data lives only in this device's browser, not on a server
