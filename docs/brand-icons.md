# PROCESS 아이콘

2026-10-28 사용자가 승인한 검은 둥근 아이콘을 적용했다. PROCESS는 PRO를 굵게, CESS를 가늘게 쓰고 아래에 작은 LETTER 또는 STUDIO를 둔다.

- 레터: `assets/brand/letter-1024-v1.png` · 공유 카드 `assets/brand/letter-share-v1.png`
- 앱: `assets/brand/studio-1024-v1.png` · 512/192/180/64 크기와 불투명 maskable 변형 · 공유 카드 `assets/brand/studio-share-v1.png`
- 공유 카드는 1200×630, 아이콘을 자르지 않는 여백을 두었다. 기존 파일명은 설치·즐겨찾기의 호환용 사본으로 유지했다.
- 새로 복사·공유하는 링크에는 `?share=letter-v1`을 붙여 기존 주소의 링크 미리보기 캐시와 구분한다. canonical 주소와 이전 링크는 계속 유효하다.
- `/assets/`는 장기 캐시되므로 이미지 내용이 바뀌면 파일명의 v1을 올린다. 카카오톡에서 이미 보낸 메시지의 캐시나 설치된 운영체제 아이콘을 강제로 바꾸지는 않는다.

## 제작 기록

내장 imagegen으로 승인 시안의 두 아이콘을 각각 분리했다(CLI 미사용). 요청 내용은 다음과 같다.

- LETTER: 승인 시안 왼쪽 아이콘의 검은 둥근 사각형, PROCESS 타이포와 작은 LETTER를 유지한다. 다른 아이콘·배경·외부 그림자를 제거하고 바깥은 투명하게, 단독 정사각형 아이콘으로 만든다.
- STUDIO: 승인 시안 오른쪽 아이콘을 같은 방식으로 분리한다. PROCESS 아래 작은 STUDIO의 글자와 간격을 유지한다.

배포용 크기는 원본의 비율을 유지하여 축소했다. 일반 앱 아이콘은 투명도를 보존하고 maskable은 불투명 배경으로 내보냈다.

## 배포 범위

기존 3.201 기능을 보존하고 승인한 아이콘과 공유 미리보기 갱신만 3.202로 적용한다. 실서버와 테스트 사이트는 같은 검증된 커밋을 사용한다.
