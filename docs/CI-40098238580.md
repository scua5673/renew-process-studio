# 9af3a112 배포 검증: 상대 분석 미팅 메모 검사

staging 6943435f0f553844c6ba3d948ea22a5ef952c7db의 CI40098238580에서 WebKit IDP 묶음의 match-meet-parts가 실패했다. 상대 분석 미팅의 국면 제목은 있었지만 시험 메모가 모두 비었다.

기존 검사는 matchGet() 객체를 직접 바꾸고 실제 input/저장 경로를 거치지 않았다. 정상 __matchRefresh가 이 사이에 실행되면 저장된 문서를 다시 읽어 주입한 메모가 사라진다. 같은 코드에서 이 새로 읽기를 넣어 before=시험 메모/after=null과 CI의 빈 메모 결과를 강제로 재현했다. 실제 textarea.fill의 input 이벤트→저장 완료→동일 새로 읽기에서는 메모가 유지되고 미팅 가져오기가 통과했다.

앱 저장 코드를 바꾸거나 기대값을 낮추지 않고, 검사를 실제 입력·저장 경로로 고친다. 동일 새로 읽기 뒤 원문이 유지되는지도 검증한다. 이전 실패 원문과 두 격리 재현 로그는 로컬 검증 기록에 보존한다.
