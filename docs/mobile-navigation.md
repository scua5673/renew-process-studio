# 휴대폰 하단 여섯 메뉴

휴대폰에서 팀 운영에 들어가도 커뮤니티를 한 번에 열 수 있게 한다. 사용자 승인한 순서는 보드 · 보관함 · 커뮤니티 · 팀 운영 · 학습 · 더보기다.

- 767px 이하 일반 셸에서 기존 단추를 이동하며, 역할 판정과 저장 장벽을 포함한 기존 클릭 핸들러를 그대로 사용한다.
- 팀의 오늘 · 경기 · 일정 · 선수단 · IDP · 더보기는 내용 위에 둔다. 경기 전체 보기와 미팅 편집의 기존 전용 화면 처리는 유지한다.
- 더보기의 IDP는 기존 전역 IDP 단추를 누르는 것과 같다. 코치는 팀 IDP, 개인 공간은 개인 IDP를 연다.
- 넓은 화면으로 돌아오거나 선수 전용 IDP 셸에 진입하면 원래 단추 순서를 복원한다.
- 두 더보기 메뉴가 겹쳐 열리지 않게 닫는다. 원본 데이터, 저장 키와 서버 API 변경은 없다.
- 320px 화면에서는 계정 이름이 줄어들어 설정 단추를 밀어내지 않는다.

검증은 실제 앱 셸과 외부 통신을 막은 합성 자료로 실행한다. `mobile-navigation` 브라우저 시험은 Chromium/WebKit의 네 화면 폭, 여섯 메뉴의 이동·크기·순서, 팀/개인 IDP, 비로그인 커뮤니티, 태블릿 전환을 확인한다. 기존 `phone-app-more`, `phone-start`, `team-mobile`, `ipad-team-navigation`도 관련 회귀를 확인한다. 실기기와 카카오톡 인앱 브라우저 점검은 배포 후 별도로 필요하다.
