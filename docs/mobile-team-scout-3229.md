## 휴대폰 글자와 간격

사용자 «폰트가 너무 커, 핸드폰으로 보기 이상적으로» 요청. 기존 team-mobile.css의 600px 이하에서 제목·큰 숫자를20→16px, 도구 버튼을12px로 정리한다. 선수 이름12px·소속11px 및 입력16px는 유지한다. 44px 터치 영역을 유지하며 통계 띠의 여백과 라벨 줄바꿈을 줄인다. 검색 바로 옆 필터 버튼으로 포지션·단계·미평가를 펼치고, 적용 중인 조건 수를 접힌 버튼에 표시한다. 펼침 상태는 기존 작업 공간 메모리에만 두며 저장 키를 추가하지 않는다. 기본 도구 줄은 세 줄에서 두 줄로 줄었다. 후보 등록은 기존 편집 도구 경로로 열고 카드를 가리던 중복 빠른 등록 플로팅 버튼은 읽기 화면에서 숨긴다.

## 스카우팅 후보 드래그

후속 «포지션별 후보 뎁스에서 바로 드래그해서 순서» 요청은 카드 안 후보 선수 순서를 기준으로 작업했다. 사용자가 후속 답변에서 카드 안의 후보 선수 순서로 확정했다. 기존 후보 이름 직접 드래그가 Chromium 실제 터치 입력으로 동작함을 먼저 확인했다. 이전 preview는 정지 이미지였다. 순서 변경 안내를 카드 위에 표시하고, 종료 시점의 클릭 억제 시간을 갱신해 오래 끈 뒤 상세창이 잘못 열리는 경우를 막았다. 이름 영역의 텍스트 선택/길게 누르기 메뉴를 억제하되 touch-action:none을 주지 않아 보통 스크롤을 유지한다. 같은 포지션 내 재정렬은 기존 sbSeat를 보존한다.
