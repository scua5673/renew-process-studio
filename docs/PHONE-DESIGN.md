# 휴대폰 디자인 통일 · 3.269

2026-11-09 사용자가 전체 비교 화면의 통일안을 승인했다. 13개 앱 문서에 `phone-consistency.css`를 연결한다. 기존 tokens.css의 글자·색·간격·모서리를 사용하며, 화면 폭 767px 이하의 화면 매체에만 적용한다.

- 버튼·탭·입력 글자와 제어 크기를 통일하고 보관함 정렬·노트 색상 도구의 작은 터치 영역을 보완한다.
- 설정은 톱니바퀴 아래에 유지한다. 설명과 버튼은 세로로 배치하고, 긴 내용은 창 내부에서 스크롤한다.
- 설정창의 부모 appbar가 만드는 쌓임 맥락을 올려 팀 탐색 메뉴가 제목과 닫기 버튼을 가리던 문제를 해결한다.
- 그림 캔버스의 작품, 내보내기·인쇄 및 768px 이상 화면의 레이아웃은 별도 규칙을 유지한다.

기존 CSS의 ID 우선순위와 강제 규칙 때문에 공통 시트에 한정된 강제 대체를 사용한다. 스타일 래칫의 증가는 이 파일의 실제 개수만 허용한다. 새로운 임의 색이나 px 글자 크기를 허용하지 않는다. 다음 정리에서 원래 규칙을 제거하면 상한도 함께 내린다.

검증: 가상 계정으로 주요 화면 20종 × 밝은/어두운 화면을 직접 열어 캡처·가로 넘침을 확인한다. 자동 브라우저 검사는 설정창의 실제 클릭 가능 여부, 설정 탭 이동과 닫기, 보관함 버튼 크기와 노트 화면을 검사한다. 실제 기기 확인과 브라우저의 휴대폰 크기 검사는 구분해서 기록한다.
