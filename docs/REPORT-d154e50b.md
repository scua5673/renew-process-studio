# d154e50b: 복제 장면의 도구가 재생 중 흐려짐

제보 ID: d154e50b-2b25-4d08-985e-f0476cd11c76. v3.157에서 운동장을 90도 회전한 뒤 복제한 장면 사이에 선·도형이 깜빡인다는 제보를 담당한다.

합성 자료에서 새 장면 복제는 정상이지만, 이전 버전에서 저장한 동일한 두 장면을 불러온 뒤 회전하면 활성 장면에만 도구 식별자 `_sceneId`가 추가되는 경로를 재현했다. 그림 내용은 같은데 재생의 내용 비교가 내부 식별자까지 포함해 사라지는 그림/나타나는 그림으로 취급한다.

검증 계획: 저장된 옛 장면과 새 복제 장면의 0·90·180·270도 재생, 실제 SVG 투명도, 그림 개수, 내용이 다른 도구의 기존 서서히 표시, 저장·다시 열기·내보내기, Chromium/WebKit 네 폭과 필수 CI 및 staging 게시 코드. 실제 iPadOS 종료는 별도 미확인으로 유지한다.

함께 확인한 텍스트의 모든 장면 위치 고정(85f9a8bd), 이후 장면 리셋 단축키(5b2fb3cd)는 별도 기능 검토로 남긴다.
