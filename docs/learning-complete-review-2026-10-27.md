# 학습 전수 검토 및 구현 결과

2026-10-27 · 로컬 v3.186 · 운영 배포 전

학습을 **오늘 이어 읽기 → 오늘 복습 → 역할별 교재 → 펼쳐 보는 목차 → 함께 읽는 책** 순서로 정리했다. 책 안에서는 장과 절의 관계를 유지하고, 한 절은 읽기와 확인을 중심으로 보여 준다. 실제 실습이 있는 17절만 해보기 단계를 갖는다. 서술형 답과 참고자료는 필요할 때 펼친다.

이번 추가 검토의 범위는 학습이다. 커뮤니티의 앞선 변경과 검토 기록은 별도 문서에 남아 있다.

## 내용 교정

- **규칙:** 오프사이드와 세이브, 페널티킥 이중 접촉, 득점 기회 저지, 적용 판별 VAR 범위를 다시 대조했다. 풋살의 골키퍼 재접촉·4초·재개 거리·누적 파울 규칙을 바로잡고 장별 기준 답과 맞췄다.
- **선수·코칭:** 스캐닝 두 번, 전환 3~5초, 수비 거리, 특정 패턴 수 등을 모든 상황의 정답처럼 쓰던 문장을 고쳤다. 개인차와 경기 맥락, 관찰할 행동을 함께 설명한다.
- **자격·교육:** 입문·발전·심화를 공식 KFA·UEFA 자격과 대응시키지 않는다. 자체 관찰 틀, 예시 일정, 협회 자료의 실제 권고를 구분한다.
- **부하·성장:** 급성/만성 부하 비율을 개인 부상 예측이나 안전선으로 쓰지 않는다. 상대 연령과 생물학적 성숙, 노출 시간과 부상 건수, 계획한 RPE와 실제 반응을 구분한다. 일률적인 증량률·훈련 요일·회복 시간을 단정하지 않는다.
- **건강·응급·복귀:** 통증과 절뚝거림을 정상 성장으로 넘기지 않도록 수정했다. 뇌진탕 의심 시 중단·평가, 응급 대응, 단계적 복귀와 의료진 판단을 반영했다. 기능 검사나 증상 소실만으로 복귀 가능하다고 단정하지 않는다.
- **분석:** PPDA·xG·표본·관찰과 인과관계의 한계를 보완했다. 데이터가 없다는 것을 0으로 처리하거나 한 장면을 원인으로 확정하는 설명을 고쳤다.
- **실습:** 17절의 버튼 목적지와 안내를 현재 플레이북·개인 IDP·팀 IDP·선수단·일정·훈련 설계·경기 화면에 맞췄다. 팀 편집 권한과 선수 계정 연결이 필요한 조건도 표시한다.

304절 모두 참고자료 링크를 갖는다. 최종 고유 URL은 38개이며, 기관의 자료 포털과 특정 주장에 대한 직접 문헌은 성격이 다르다고 표시했다. NSCA의 실제 404 주소는 현재 공식 자료로 교체했다. KFA·RBFA처럼 동적으로 표시되는 포털은 검색 결과·문서 제목으로 존재를 확인했으며, 포털 전체 내용의 학술적 검증을 의미하지 않는다.

## 사용 중 발견해 고친 동작

1. 새로고침 뒤 읽는 책으로 들어가면 마지막 절을 다시 연다. 먼저 묻기·꺼내기·왜의 입력과 답 공개 상태를 보존한다.
2. 복습은 선택한 교재와 무관하게 카드의 원래 절에서 질문과 기준 답을 가져온다. 제목에 답을 미리 보여 주지 않는다.
3. 재도전해도 이미 완료한 진도를 지우지 않는다. 다시 틀린 카드는 다음 날 복습으로 돌리고, 이미 가까이 잡힌 복습을 정답 클릭으로 늦추지 않는다.
4. 풋살 장 식별자와 기준 답 누락을 수정했다. 완료·카드 ID는 유지한다.
5. 실습으로 이동할 때 사전 로딩이 취소된 빈 프레임 때문에 화면이 계속 비던 문제를 고쳤다. 로딩 시작 후 8초가 지나도 `about:blank`인 프레임만 다음 이동 시 재요청한다. 열린 편집 화면은 다시 불러오지 않는다.
6. 좁은 데스크톱 창에서 학습 프레임을 768px로 강제 축소하던 적용을 해제했다. 학습은 실제 폭에 따라 한 열로 재배치된다.
7. 목차의 절과 장별 복습을 실제 버튼으로 바꿔 키보드로 실행할 수 있게 했다.

자동 검사는 304절의 모든 선택지, 오답·재시도·완료, 서술형 저장, 다른 교재에서의 복습, 복습 일정, 숙달 후 재오답, 다음 절 이동을 실행한다. 96개 장의 571문항은 렌더링·기준 답·채점·다음 문항·결과 저장을 검사한다.

실제 Chrome에서는 304절을 모두 열어 오답 → 재도전 → 정답 → 다음 절을 실행했다. 이 전수 클릭 이후의 추가 문구 교정은 최종 자동 검사와 실제 화면 표본 재검토로 확인했다. 모든 문구 변경 후 304절을 다시 수동 클릭했다는 뜻은 아니다.

17개 실습 버튼은 전부 실행해 올바른 화면 도착을 확인했다. 별도로 가상 자료에서 다음 저장 흐름을 실행했다.

- 플레이북: 팀 정체성, 국면, 세부 국면, 원칙 작성 및 저장.
- 개인 IDP: 목표 입력과 오늘 기록 연결.
- 훈련 설계: 카드 작성, 저장, 보관함에서 확인.
- 일정: 훈련 주제·블록·메모 입력과 세션 표시 확인.
- 팀 IDP: 가상 선수 평가 저장과 면담 입력.
- 경기: 리뷰 세 필드 저장, 재열기 후 내용 보존, 개선점을 일정의 훈련 과제로 연결.
- 학습: 새로고침 후 이어 읽기 및 세 서술형 답 복원, 복습 답 공개 후 입력 보존, 다른 책의 원래 절 이동, 목차 Enter 실행.

375×812, 1100×900, 1280×1100의 Chrome 화면을 확인하고 캡처했다. 375px에서는 학습 문서의 실제 폭과 스크롤 폭이 모두 375px임을 확인했다.

## 검증의 한계와 배포 상태

실제 사용자·팀 자료는 쓰지 않았다. 로컬 가상 백엔드의 별도 계정·선수 자료로 검사했다. 선수 계정 연결이 없는 상태라 연결된 선수의 실제 일지 수신과 피드백 전달, 여러 기기 간 동기화까지 완료했다고 보지 않는다. 실제 iPhone·Android·iPad와 WebKit 검증도 별도다.

내용 검토는 편집·문항 일관성과 주요 규칙·의학·연구 해석에 대한 원문 대조다. 공식 지도자 과정 인증이나 임상 전문가 감수를 대신하지 않는다.

작업은 로컬 브랜치 `codex/learning-community-hierarchy`에 있다. 푸시·PR·운영 배포는 하지 않았다. 배포 시점에는 당시 staging 버전에 맞춰 판 번호 충돌 여부를 다시 확인해야 한다.

증거 파일은 프로젝트의 `outputs/2026-10-26-learning-complete/`에 있다: `lessons-final.json`, `sources-final.json`, `lesson-content-diff.json`, `browser-lessons.json`, `browser-practices.json`, `browser-match-to-training.json`, 화면 캡처, 테스트 로그. `lessons.json`과 역할별 텍스트 파일은 교정 전 검토 사본으로 유지했다.
