# 팀·학년과 일정 연결

`grp`는 일정, 선수, 경기, 하루별 훈련/OFF와 옛 `grpWeeks`에서 공유하는 연결 키다. 기존 키는 바꾸지 않는다. 조 이름 변경은 `scout_tool_v1.meta.grpLabels`의 표시 이름만 수정하며, `grpBase`의 개수·순서나 선수 배정·일정 문서를 수정하지 않는다. 새 조는 이름과 무관한 키를 만든다. 공개 명단과 작전판용 미러에도 표시 이름을 전달한다.

선수의 `schoolYear`와 훈련 세션의 `schoolYears`는 1·2·3 문자열이다. 평가 등급 `grade`를 사용하지 않는다. 값이 없는 기존 세션은 전체 학년이다. 팀 여러 개와 학년 여러 개는 각각 합집합이고, 두 조건 사이에는 교집합을 적용한다. 예를 들어 A·B팀과 1·2학년을 고르면 두 팀의 1·2학년 선수들이 대상이다. 학년이 미지정인 선수는 제한된 학년의 개인 초점 참고에서 제외한다.

과거 `1학년`, `2학년`, `3학년`을 조 이름으로 사용한 자료는 자동 변환하지 않는다. 기존 조의 합집합 의미를 새 팀×학년 의미로 바꾸면 참여 대상이 달라지기 때문이다. 기존 조는 표시하고 원래 참조를 유지하며, 새 세션 추가의 팀 선택에서는 분리한다. 기존 조로 필터링 중이라면 해당 조를 그대로 선택해 이어서 작성할 수 있다.

세션 추가 확인 전 선택은 임시 상태다. 취소는 쓰지 않고, 팀/계정·날짜 객체·편집 권한이 바뀌면 확인을 거절한다. 이름 변경 창도 같은 소유자·조 목록·이름을 다시 확인하며, 빈 이름과 중복 이름을 거절한다. 필터 변경은 서버 문서를 쓰지 않는다. 학년별 표시는 세션과 같은 슬롯에 붙은 훈련·미팅·준비운동 배열을 함께 거르는 사본으로 만든다. 세션 ID와 훈련 ID는 재발급하지 않는다.

현재 학년 선택은 세션 추가/채우기와 선수 명단에 제공한다. 월간 빠른 시간대 입력은 기존 하루 일정 방식이며 상세 대상은 ‘주간에서 열기’에서 지정한다. 날짜의 경기·OFF는 기존대로 하루/팀 범위다. 이번 변경은 학년별 하루 OFF 모델이나 일정 충돌 자동 방지까지 바꾸지 않는다.

검증은 합성 팀만 사용한다. 이름 변경 전후 일정 JSON·선수 목록·연결 키가 같고 일정 쓰기가 추가되지 않는지, 학년별 훈련을 저장하고 재접속해도 슬롯·훈련·학년이 유지되는지 확인한다. 실제 staging/운영 반영 전에는 최신 staging과 판 번호를 다시 대조한다.
