# 자료별 커뮤니티 카드

사용자가 2026-10-30 `community-content-cards.html` 목업을 확인하고 «오케이»로 승인한 카드 구성을 기존 탐색형 구현에 적용했다. 준비 판은 3.223이며, 3.222 탐색형과 함께 로컬 `codex/community-explore`에 있다. 원격 push·PR·운영 배포 전이다. 후속 배포 시 최신 staging과 판 번호를 확인한다.

- 레터는 호수·제목·소개·읽음/반응·하단 읽기 동작의 독립 카드다. PC 3열, 태블릿 2열, 휴대폰 1열이며 제목은 자르지 않는다. 원문, 정렬, 검색, 읽음 기록, 집계 조회는 기존 경로를 유지한다.
- 트레이닝은 실제 썸네일·목적·제목·요약·형태를 보여주고 하단에 기존 카탈로그의 훈련 개수와 인원 범위를 표시한다. 목적별 탐색 화면과 실제 훈련 열기 경로는 유지한다.
- 코치 카드에는 요약과 자연스러운 제목 줄바꿈을 적용했다. 기존 작성자·통계·좋아요를 보존하고 하단에 `자료 보기`를 둔다. 기존 카드/큰 카드 보기에서만 그림과 본문의 위계를 조정하며 엘미하 영상 카드는 기존 모듈이 처리한다.
- FIFA 작전판 카드는 기존 그림 선택과 재생을 보존하고 `훈련 보기`와 `원문` 동작을 분리한다. 작전판이 없는 항목은 작은 외부 자료 카드다. 현재 배포 소스의 FIFA 193개 항목에는 모두 작전판이 있으므로 외부 전용 형태는 기존 폴백을 검증하는 경우에만 나타났다. 준비된 작전판을 제거하거나 외부 링크로 바꾸지 않았다.
- 색·글자·모서리는 기존 디자인 토큰을 사용한다. 새 `community-cards.css`는 서비스 워커 CORE에 등록한다. 데이터, 원문, 권한, 동기화 변경은 없다.

## 검증

- 단위 5,345개 통과. 스타일 래칫과 기존 자료·XSS 검사를 포함한다.
- `community-library`: 실제 앱의 Chromium PC / WebKit 태블릿·휴대폰 1280·1100·320·375·393px. 46개 레터, 검색·정렬·읽기·읽음, 필터와 반응형 복귀 통과.
- `community-cards`: Chromium 1280px / WebKit 1100·320·393px. 네 자료 형태의 폭·제목·44px 버튼, 코치/훈련/FIFA 뷰어 열기, 외부 링크 새 탭과 뷰어 중복 열기 방지 통과. 훈련 수·인원은 실제 카탈로그에서 읽으며 게시물·계정은 합성 자료다. FIFA index만 첫 세 작전판을 남긴 응답으로 제공해 외부 링크 폴백도 검사했다. 이 테스트는 critical storage 묶음에 포함하며 내부에서 두 엔진을 쓰므로 한 번만 실행한다.
- `community-process`: WebKit 휴대폰에서 레터 본문 138편, 훈련 세션 45개, 읽음 지속·오류 재시도·늦은 응답·훈련 가져오기 통과.
- `community-youtube`: WebKit 휴대폰에서 다섯 썸네일과 외부 링크, 320·390·767·1100px, 이미지 폴백, 합성 업로드·재열기 통과.
- 실제 계정·운영 데이터는 사용하지 않았다. 물리 기기·카카오톡 내장 브라우저·전체 원격 CI는 미실행이다.

작업 공간 `outputs/2026-10-30-community-content-cards/`의 `applied-preview.html`에 실제 적용 화면을 모았다. `preview.html`은 앞선 제안 목업이므로 적용 증거와 구분한다. 로그와 세부 치수는 같은 폴더의 JSON 및 하위 `library/`, `applied/`에 있다.
