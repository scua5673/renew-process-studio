# 커뮤니티 탐색형 화면

사용자가 승인한 탐색형 목업을 기존 커뮤니티 화면에 적용한다. 기준은 main/staging의 16821dcb(3.220)이며 준비 판은 3.222다. 별도로 준비 중인 보드 디자인 3.221은 포함하지 않았다. 배포 시 최신 staging과 판 번호를 다시 확인한다.

- 소개는 `커뮤니티 · 자료를 찾아, 내 현장으로.`로 줄이고 검색을 다섯 분류 위에 둔다. 같은 검색 input과 이벤트를 사용한다. 모바일 분류 개수는 숨기고 목록의 실제 결과 개수를 유지한다.
- 모바일 경계는 767px로 맞춘다. 기존 연령·인원 고르개의 필터 시트 이동을 유지하고, 주제·대상 분류는 native details로 펼친다. 넓은 화면으로 바꾸면 분류를 펼치고 기존 필터를 되돌린다.
- 레터 목록의 두 번째 소개를 제목과 정렬 줄로 줄인다. 번호 표지, 제목, 두 줄 소개, 실제 읽음·반응 정보를 표시하며 본문과 읽음 저장 경로를 유지한다.
- 엘미하 카드는 기존 YouTube 매핑과 폴백을 유지한다. 전술 보기와 영상 보기는 DOM과 화면 모두 같은 순서로 배치한다. 영상 링크는 기존 새 탭 경로이며 카드의 전술 열기를 동시에 실행하지 않는다. 비어 있는 분류에서 생성되던 `기타` 표시는 영상 카드에서만 생략한다.
- 상단 셸, 하단 여섯 메뉴, 계정·권한, 원문·데이터·동기화 저장 경로는 변경하지 않는다. 상세 뷰어 스타일도 유지한다.

검증은 실제 계정 대신 로컬 합성 API와 테스트 계정으로 수행했다. 기존 공개 영상 이미지 사본은 검토용 실행에만 사용하며 저장소에는 추가하지 않는다.

## 검사

- `npm test`: 5,345개 통과.
- `npm run test:sql`: 통과. 메모리 PostgreSQL에서 실행하며 운영 DB에 연결하지 않는다.
- `community-library`: Chromium PC, WebKit iPad·휴대폰. 1280/1100/320/375/393px, 검색과 정렬, 전체 레터, 읽기·읽음 표시, 공유 메뉴, 다섯 분류 터치 영역, 필터 펼치기와 반응형 복귀.
- `community-youtube`: Chromium/WebKit, 320/390/767/1100px. 다섯 썸네일, 16:9 비율, 두 행동의 44px 터치 영역, 새 탭, 이미지 폴백, 잘못된 링크 거절, 합성 업로드와 재열기.
- `community-detail`: Chromium PC와 WebKit 태블릿·휴대폰. 기존 작전판 뷰어, 내용 탭, 훈련 전환, 보관함 연결과 닫기.
- `community-process`: WebKit 휴대폰에서 레터 46편·본문 138편·훈련 세션 45개, 훈련 가져오기, 분류 전환, FIFA 필터.

증거는 작업 공간의 `outputs/2026-10-30-community-explore/`에 보관한다. 물리 휴대폰·카카오톡 인앱 브라우저와 전체 CI는 미실행이다. 원격 push·PR·운영 배포는 이 준비 작업에 포함하지 않았다.
