# 관리자 운영 개선 작업

2026-11-02 사용자 승인: 실제 관리자 페이지 점검 후 권장 개선을 진행한다. 후속 요청은 Codex 클라우드 개발 환경 구축이며 관리자 변경은 이 작업 사본에 보존한다.

기준: `994d8b132f8ec7feef2cc199e2f209b13d59f78d` / `origin/staging` / 앱 3.236.
작업 가지: `codex/admin-operations-upgrade`.
별도 시즌 수정 초안 PR #735는 포함하지 않는다.

## 변경

- `admin-data.js`: 기간을 고정하고 시각·ID 커서로 사용 이벤트를 끝까지 조회한다. 서버가 요청보다 작은 페이지를 주어도 계속 읽고, 실패·상한·계정 변경은 불완전 성공으로 발행하지 않는다.
- 관리자 목록 RPC는 안정된 정렬·offset으로 페이지를 이어 읽는다. 팀 목록은 현재 응답하는 `ps_admin_activity_ws`를 사용하며 콘텐츠 수·소유자 메타데이터를 별도로 연결한다. 생성 시각 등 수집되지 않은 필드는 만들지 않는다.
- 공통 통계는 자료별 성공 여부를 확인한다. 조회 실패와 실제 0을 구분하며 각 자료의 응답 시각을 제공한다.
- 명시 새로고침은 오류·사용 방식·IDP 캐시도 갱신한다. 사용 방식·팀 상세·활동·홈·IDP 조회에는 세대·계정 경계를 둔다.
- 운영 홈의 `admin-hub.js`는 최근 저장 보고·실패한 조회·열린 후속 기록을 연결한다. 실제 기록 생성·상태 변경은 기존 사용자 상세의 저장 경로를 사용한다.
- 용량 제한·선수 사본 불일치·업데이트 설치 실패의 설명과 안전한 조치 안내를 개선한다. IDP 문서 갱신과 일지 작성, 기록 사고 이후 경과일과 사고 부재를 구분한다.
- 활동 정렬과 기능 이름을 보강한다. 노트북 홈의 고정 3행 구성을 새 영역에 맞춰 자연스러운 페이지 흐름으로 변경한다.

## 확인한 것

- 첫 전체 단위 검사 5,381개 통과. 이후 홈 CSS 변경은 재검사 전이다.
- 관리자 검사 239개 통과. 페이지 상한·누락·늦은 응답·조회 실패·원문 보존을 실행 기반으로 검증했다.
- 합성 로컬 화면에서 팀 목록 1개·콘텐츠 2개 일치, 서버 페이지 상한 200개에서도 사용 통계 1,251개 표시를 확인했다.
- SQL 전체 검사는 진행 기록을 별도 출력 폴더에 남긴다.

## 남은 확인

- 홈 CSS 수정 이후 표시·겹침·375/393/768/1280 폭 확인.
- 기존 브라우저 픽스처의 RPC offset 응답 보강 및 회귀 검사. 브라우저 조작은 현재 환경에서는 CUA만 사용한다.
- 일부 팀 상세 조회 실패가 0으로 보이는 경로 및 홈의 누락된 부가지표 상태까지 점검한다.
- 사용자별 후속관리 진입·저장 후 목록 재조회 확인. 합성 계정으로만 검증한다.
