# 3.154 보드 제보 담당 기록

사용자가 새 제보 확인과 해결을 요청했고, 현재 화면을 유지하며 세 개선을 모두 반영하도록 선택했다.

- 229361bb-a0f5-424f-9526-4a6667cf18b2: 3D 토큰 강조 가시성.
- b3c02cfe-af0f-44db-8570-c9951b6154bc: 텍스트 제자리 편집 및 고정 상태에서 내용 편집.
- 9a418a56-c98c-4fa7-a007-d6de33e0f8cf: 텍스트와 토큰의 앞뒤 배치, 배경 투명도, 내용에 맞는 배경 폭.

현재 제보는 3.152 Chrome/macOS에서 접수됐으며 첨부 오류 로그는 0건이다. 신규 고장으로 단정하지 않고, 기존 화면의 동작을 합성 자료로 재현해 다듬는다. 실제 제보 답변/닫기/운영 데이터 수정은 하지 않는다. 구현 전 이 기록의 draft PR로 담당을 표시한다.

예정 검증: Chromium/WebKit의 폰·아이패드·데스크톱 크기, 편집/고정/레이어 순서/배경, 저장·새로고침·되돌리기·애니메이션·내보내기, 필수 단위/SQL/CI 및 staging 게시 코드. 통과 후 승인된 실사용 배포 절차를 진행한다. 실제 iPadOS 종료 해결로 간주하지 않는다.

## 재현과 수정

3.153 합성 보드에서 편집 전 글 높이 45.61px → 입력창 186px, 텍스트 배경 267 보드 단위(실제 내용+여백 78.86), «맨 앞» 후에도 토큰 아래를 확인했다. 3D 강조 반지름 27은 해당 칩 반지름 35.49보다 작았다.

- 기존 글은 최초 표시부터 내용·줄바꿈 폭·현재 배율에 맞게 편집한다. 모바일 확대를 피하는 최소 입력 글꼴과 화면 경계 처리를 함께 유지한다. 새 글 입력창의 기존 구성은 유지한다.
- 개별 고정 텍스트는 이동을 막되 두 번 눌러 편집한다. 첫 선택으로 모바일 도크가 바뀌기 전에 두 번째 누름을 판정한다. 전체 보드 잠금은 기존 규칙대로 유지한다.
- 텍스트의 `front`는 토큰 위 SVG 층에서 그리되 기존 그림 인덱스를 보존한다. 선택·그룹 이동·되돌리기·SVG 내보내기에도 같은 순서를 쓴다.
- 배경 `bgOp`는 글자 투명도와 별개이며 완료할 때만 저장한다. 수동 줄바꿈 폭은 유지하고 배경만 실제 줄 길이·정렬에 맞춘다. 기존 편집 도구 안에 배경 농도 조절을 둔다.
- 3D 강조는 실제 칩 크기에 맞춰 반지름·선 굵기를 키우고 노란 바탕을 더한다. 2D 강조 모양은 유지한다. 정적 SVG 요소로 내보내기에도 반영한다.

## 검증

- 단위 4,237개, 합성 SQL, 배포 패키징 통과.
- Chromium/WebKit 375·393·768·1280: 앞뒤 배치와 실제 포인터 적중, 고정 글 터치/더블클릭, 편집 크기, 배경 농도, 취소·되돌리기, 그룹 끌기, 장면 강조, SVG/썸네일, 합성 저장·새로고침 확인.
- 기존 도형 메뉴 Chromium 회귀 통과. 공개 staging 및 정확한 커밋 CI/production 검증은 배포 단계에서 기록한다.
- WebKit iPad는 앱의 기존 1100 CSS px 뷰포트를 기기 폭으로 축소하므로 터치 좌표에 실제 visualViewport 배율을 반영한다. 기기 폭 768에서 검사했으며 실제 iPadOS 종료 재현/해결로 간주하지 않는다.
