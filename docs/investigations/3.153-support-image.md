# 오류 제보 이미지 첨부

담당 제보: 93a76051-3643-4e7e-88f0-c650bceb5a93. 사용자가 기능 구현을 요청했다.

- 작성 화면에 이미지 한 장 선택·미리보기·삭제. 기기에서 크기/용량을 줄이고 다시 인코딩한다.
- 글과 이미지를 같은 접수로 확정하며 불명확한 응답은 같은 ID로 재확인한다.
- 제보자와 운영자만 이미지에 접근한다. 팀 문서/공개 URL/로그에 이미지를 넣지 않는다.
- 관리자 상세와 내 제보 상세에서 이미지를 확인한다.
- 합성 SQL 권한/재시도 검사, Chromium/WebKit과 네 화면 폭을 검증한다.
- 운영 DB 변경은 사람이 적용하도록 검증된 migration/runbook을 준비한다. 적용 확인 전 실사용 완료로 표시하지 않는다.

상태: 구현 및 로컬 검증 완료. 운영 SQL 적용·verify 완료 · PR #588 배포 진행.

검증: 단위 4,237건, 전체 SQL 묶음(첨부 신규 48검사), Chromium/WebKit × 375·393·768·1280px 통과. 소스 10MiB·1,200만 화소, 전송 2048px·512KiB 한도. IDB 저장 실패, 접수 전 네트워크 실패, 접수 후 응답 유실/새로고침/동일 ID 재확인, 로컬 이미지 소실 뒤 서버 접수 확인, 미설치 RPC의 글 단독 접수, 이미지 준비 중 계정 전환, 타인 열람 차단을 검증했다. 배포 파일 1,672개 패키징 통과.

사용자의 직접 실행 승인 후 로그인된 Supabase SQL Editor에서 설치·verify를 완료했다. 적용 증거는 migrations/20261023_support_images.applied.md, 운영 구조 기준본은 migrations/00000000_baseline.sql이다. 기존 제보 내용이나 계정 저장소 변경 없이 구조만 추가했다. staging/실사용 배포 확인은 별도로 진행한다.
