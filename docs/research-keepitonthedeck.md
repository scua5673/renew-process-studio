- 강점: 큰 SNS 도달(페북 50만+), 10년 넘게 쌓인 SEO 블로그, 낮은 가격(€10/월), "실제 클럽이 하는 훈련" 이라는 강한 소구, 전술 카메라 영상이라는 차별 요소.

## 3. 시장에서 보이는 흐름
1. **가격대는 월 €/£/$ 10 근처로 수렴** — KIOTD €9.99, CV £11.99(연 환산 £9.99), SCW £9.95, WCC $8.95. 도구는 연 $48~$75.
2. **콘텐츠 + 도구 합치기** — Coaches' Voice 가 SSP 를 사들인 것이 대표 사례. 보기만 하는 곳에서 "짜고 공유하는 곳" 으로.
3. **단체(클럽 · 협회) 요금** 이 큰 수익원 — SCW 코치당 $20, CV 단체 견적, Coaching Manual · AYSO, SSP · BFCN 묶음.
4. **전술 카메라 영상** 이 차별 콘텐츠로 떠오름 — KIOTD, VEO.
5. **AI 세션 생성** 이 새 진입자.
6. 마케팅 깔때기: 무료 SNS 클립(대규모 도달) → 무료 PDF · 세션 → 일회성 팩 → 월 구독.

## 4. PROCESS STUDIO 에 주는 시사점(제안)
- KIOTD 류는 "남의 세션을 본다" 에서 멈춘다. PROCESS STUDIO 는 작전판 · 훈련 · 경기 준비 · 선수단 · IDP · 커뮤니티를 **한 팀 안에서 이어 쓰는** 쪽 — SSP/TacticalPad 보다 넓고 CV Academy 보다 실무적. 이 차이를 랜딩에서 분명히.
- 커뮤니티 글(작전판 재생 · 3D 보기)을 **공개 SEO 페이지** 로 내보내면 KIOTD 블로그식 유입을 만들 수 있다(클럽 · 감독 이름 + 연습 이름이 검색어).
- 가격을 매긴다면: 개인 월 ₩1만 원대 / 연 할인, **팀 · 클럽 단위 요금** 을 중심에. 일회성 "세션 팩" 은 작전판 묶음을 내보내는 방식으로 실험 가능.
- 전술 카메라 · VEO 영상 링크를 경기 준비 · 리뷰 화면에 붙이는 연동은 수요가 확인된 영역.
- 영상 · 세션 출처 권리를 분명히 하는 것 자체가 KIOTD 대비 신뢰 차별점.
