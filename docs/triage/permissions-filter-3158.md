# 권한 관리 · 연결 안 된 선수 필터

사용자 요청: 권한 관리에서 선수 명단에 연결되지 않은 선수 계정만 볼 수 있게 한다.

- 전체 / 연결 안 된 팀원 / 연결 안 된 선수의 세 가지 표시 모드. 마지막 모드는 역할이 `player`이고 `playerId`가 없는 팀원만 표시한다. 임원·코칭스태프는 별도 팀원 모드에서 확인한다.
- 모든 편집 카드를 유지한 채 표시만 바꾼다. 필터는 팀원 재조회·권한 저장을 하지 않으며, 숨긴 팀원의 미저장 역할·범위·연결 변경과 기존 선수 연결 중복 보호를 유지한다.
- 역할/연결을 편집하면 표시 수·역할 묶음·빈 목록 안내가 갱신된다. 별도 표시 모듈은 저장소나 운영 데이터에 접근하지 않는다.
- 검증: 기존 권한 저장/경합 보호 및 새 필터 회귀, 합성 계정의 Chromium/WebKit 375·393·768·1280 화면에서 필터·편집 유지·숨은 연결 보호·저장/취소·원문 보존. 실계정 권한·선수 연결 변경 없음.
