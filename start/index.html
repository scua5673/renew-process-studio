설치는 선택이에요

위의 앱 열기로 브라우저에서 시작하세요. 자주 쓴다면 홈 화면이나 Dock에 추가할 수 있어요.

아이폰 · 아이패드

Safari에서 앱 열기 → 공유 버튼 ↑ → 홈 화면에 추가

안드로이드

Chrome으로 접속 → 메뉴 ⋮ → 홈 화면에 추가(또는 앱 설치)

맥 · PC

Chrome에서 설치 메뉴가 보이면 주소창의 설치 아이콘을 이용하세요. 맥 Safari는 macOS Sonoma 14 이상에서 공유 → Dock에 추가를 지원해요. 앱의 설정 → 기기에서도 설치 안내를 볼 수 있어요.

오프라인에서는 이 기기에 준비된 자료로 작업할 수 있어요. 첫 로그인·팀 합류·서버 동기화에는 인터넷이 필요합니다. 설치만으로 서버 저장이 완료되지는 않아요.

선수용

PLAYER
내 프로필, 내 훈련, 내 성장 기록 — 전부 내 손으로.
1

로그인하고 내 IDP 열기

앱의 계정 버튼에서 카카오로 계속 또는 Google로 계속을 누르세요. 로그인 후 앱 메뉴의 IDP를 엽니다. 화면에 따라 더보기 → 내 IDP로 표시돼요.

2

초대 코드로 팀에 합류하기

코치가 준 코드가 있다면 계정 메뉴의 코드로 합류 → 팀에서 쓸 이름 또는 아이디 입력 → 다음 → 8자리 코드 입력 → 선수로 합류. 개인으로 쓸 때는 이 단계를 건너뛰어도 돼요.

3

나를 소개하기

IDP의 내 프로필(폰에서는 프로필)에서 이름·포지션·주발부터 채워요. 같은 화면의 셀프 평가는 준비됐을 때 해보세요. 첫날부터 모든 칸을 채울 필요는 없어요.

4

오늘의 첫 기록 남기기

일지에서 오늘의 참여·컨디션·수면을 골라요. 기억하고 싶은 장면이 있다면 한 줄을 남겨도 좋아요. 입력은 자동 저장되며, 저장 중이거나 실패했다는 표시가 있으면 확인해 주세요.

5

다음에 해볼 행동 정하기

목표의 내 방향 쓰기에서 되고 싶은 선수와 해볼 행동을 적어봐요. 다음 일지에서 그 행동을 해봤는지 돌아볼 수 있어요. 코치의 피드백이 오면 읽고 내 생각도 답해 보세요.

기기 저장과 서버 동기화는 별개예요. 다른 기기로 옮기기 전 설정 → 데이터 → 지금 동기화에서 완료 상태를 확인하세요. 새 기기에서도 같은 앱 주소와 같은 계정으로 로그인하세요.
팀 합류 뒤에는 코치가 계정과 선수단 명단을 연결해야 해요. 코치 화면에서 내 기록을 찾지 못하면 합류할 때 쓴 이름을 알려주세요.
📋

코치용

COACH
팀을 만들고, 선수를 부르고, 성장을 지켜보는 순서.
1

로그인하기

앱의 계정 버튼에서 카카오로 계속 또는 Google로 계속으로 로그인하세요. 이미 사용 중이라면 기록을 만든 같은 계정을 사용하세요.

2

팀과 선수단 명단 만들기

계정 메뉴의 ＋ 팀 만들기에서 팀 이름을 정하세요. 만든 팀으로 들어가 선수단에 선수를 등록합니다. 이 명단을 나중에 선수 계정과 연결해요.

3

초대 메시지 보내기

계정 메뉴의 팀 관리에서 초대 코드 만들기 → 초대 메시지 복사. 팀원에게 전달하면 로그인 후 코드로 합류할 수 있어요. 코치도 처음에는 선수 역할로 합류합니다.

4

역할을 정하고 선수 연결하기

관리자가 팀 관리 → 권한 관리에서 합류한 사람의 역할을 임원 / 코칭스태프 / 선수 중에서 정합니다. 선수는 선수 연결에서 명단의 본인을 고르고 저장하세요. 코칭스태프의 팀 자료 편집은 기본적으로 닫혀 있어, 필요하면 여기서 편집 범위를 정합니다.

5

첫 기록을 보고 피드백하기

팀 메뉴의 IDP에서 연결된 선수를 골라 기록을 확인하세요. 선수의 원문은 선수가 쓰고, 코치는 별도의 피드백을 남깁니다. 처음에는 선수 한 명의 일지와 코치 피드백이 서로 보이는지 확인해 보세요.

💡 첫 사용 순서 — 선수 한 명과 로그인·합류·선수 연결·첫 기록 확인까지 해본 뒤 팀 전체에 안내하세요. 초대 메시지에 이 페이지 링크를 함께 넣으면 같은 순서로 시작할 수 있어요.
💬

자주 묻는 질문

인터넷 없이도 되나요?

이 기기에 준비된 자료는 오프라인에서도 일부 열고 편집할 수 있어요. 로그인·팀 합류·새 자료 받기·서버 동기화는 인터넷이 필요합니다. 다시 연결한 뒤 동기화 상태를 확인하세요.

로그인 안 하면 못 쓰나요?

작전판과 커뮤니티는 먼저 둘러볼 수 있어요. 내 IDP·보관함·팀 기능을 사용하려면 로그인하세요.

내 기록을 팀원들이 다 보나요?

IDP 원문은 본인만 편집하고, 팀에 합류하면 코치·스태프가 성장 기록을 열람하고 피드백할 수 있어요. 다른 선수에게 내 IDP를 열어주지는 않습니다. IDP 이미지노트와 개인 노트는 팀에 공유되지 않아요. 개인 노트와 개인 공간의 IDP는 계정으로 서버 동기화됩니다. 비공개와 기기 전용은 다른 뜻이에요.

팀에 합류했는데 코치가 내 기록을 못 찾아요

먼저 같은 팀이 선택됐는지, 설정 → 데이터에서 동기화됐는지 확인하세요. 관리자가 권한 관리 → 선수 연결에서 내 계정을 선수단의 본인과 연결하고 저장했는지도 확인해야 해요.
