IDP 시작 가이드

순서대로 4단계 — 사진 그대로 따라 하면 끝나요.

1

열기

아래 버튼을 누르면 내 IDP 화면이 바로 열립니다.

내 IDP 열기 →
2

홈 화면에 추가

앱처럼 쓰기 위해 홈 화면에 추가합니다. 내 폰을 고르세요.

Safari로 연 상태에서 → 아래 공유 버튼(⬆︎) → 홈 화면에 추가 → 추가. 홈에 PROCESS 아이콘이 생깁니다.

Chrome으로 연 상태에서 → 오른쪽 위 ⋮ 메뉴 → 앱 설치(또는 홈 화면에 추가) → 설치.

3

로그인 — 꼭!

홈 화면 아이콘으로 다시 열고, 오른쪽 위 [로그인] 버튼을 누르세요.

빨간 동그라미 — 오른쪽 위 [로그인]

카카오로 계속을 누르면 끝. 로그인해야 폰을 바꾸거나 지워도 기록이 안 사라집니다.

노란 버튼 [카카오로 계속]
4

3단계 따라가기

첫 화면이 순서대로 안내합니다 — ① 프로필 만들기 → ② 나를 평가하기 → ③ 이번 달 목표. 여기까지 하면 나만의 성장 대시보드 완성!

IDP 첫 화면 — 3단계를 순서대로 탭

그다음부터는 하루 10초 — 일정 탭에서 오늘 날짜를 누르고 훈련/경기/휴식 + 강도만 체크하세요.

공유 버튼이 안 보여요 (아이폰) — 카카오톡 안에서 열면 안 보일 수 있어요. 오른쪽 아래 ⋯ → Safari로 열기 후 다시 하세요.
앱 설치가 안 보여요 (안드로이드) — 새로고침하고 잠깐 사용한 뒤 ⋮ 메뉴를 다시 열어 보세요.
로그인 버튼이 없어요 — 이미 로그인된 상태예요. 오른쪽 위에 내 계정 아이콘이 보이면 완료.
