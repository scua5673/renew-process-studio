IDP 시작 가이드

로그인부터 첫 기록까지 — 순서대로 따라오세요.

1

열기

아래 버튼으로 내 IDP를 여세요. 아직 로그인하지 않았다면 로그인 화면이 나옵니다.

내 IDP 열기 →
2

홈 화면에 추가

설치는 선택입니다. 자주 쓴다면 홈 화면에 추가하세요. 내 폰을 고르세요.

Safari로 연 상태에서 → 아래 공유 버튼(⬆︎) → 홈 화면에 추가 → 추가. 홈에 PROCESS 아이콘이 생깁니다.

Chrome으로 연 상태에서 → 오른쪽 위 ⋮ 메뉴 → 앱 설치(또는 홈 화면에 추가) → 설치.

3

로그인 — 꼭!

앱을 열면 나오는 로그인 화면에서 시작하세요. 계정을 바꾸거나 확인할 때는 계정 메뉴를 여세요.

카카오로 계속 또는 Google로 계속을 선택하세요. 다른 기기에서는 같은 계정으로 로그인하면 동기화된 기록을 받을 수 있습니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 저장·동기화 상태를 확인하세요.

4

3단계 따라가기

첫 화면의 안내를 따라 ① 내 이름과 자리 적기 → ② 오늘 한 장 남기기 → ③ 내가 잘하는 것 평가해 보기부터 시작하세요. 팀에 함께 쓸 때는 코치에게 받은 합류 코드로 들어가고, 내 선수 프로필이 연결됐는지 확인하세요.

목표 → 내 방향 쓰기에서 되고 싶은 선수 모습과 이번에 해볼 행동 하나를 적어 보세요. 저장하고 오늘 기록하기를 누르면 오늘 일지로 이어집니다. 행동을 해본 정도와 장면 한 마디를 남기고, 지난 일지·주간 회고에서 다시 확인할 수 있습니다.

공유 버튼이 안 보여요 (아이폰) — 카카오톡 안에서 열면 안 보일 수 있어요. 오른쪽 아래 ⋯ → Safari로 열기 후 다시 하세요.
앱 설치가 안 보여요 (안드로이드) — 새로고침하고 잠깐 사용한 뒤 ⋮ 메뉴를 다시 열어 보세요.
로그인 버튼이 없어요 — 계정 메뉴에서 로그인한 계정을 확인하세요. 로그인되어 있어도 저장 대기나 오류가 보이면 동기화 상태를 먼저 확인하세요.
