# 애니띵 모닝 (Anything Morning)

아침 5분, 무엇이든 조금씩.
누구나 매일 조금씩 공부해서 **말이 달라지고, 간단한 대화가 열리는** 앱입니다.

PROCESS STUDIO와는 **별개의 앱**입니다. 이 폴더 안의 파일만으로 동작하며, PROCESS STUDIO 배포(`scripts/package-site.mjs`)에는 포함되지 않습니다.

## 과정

| 과정 | 무엇을 | 분량 | 직접 써 보기 |
|---|---|---|---|
| “ 좋은 문장 | 코치·부모·리더가 사람을 설득하고 힘을 주는 문장 | 10개 상황 × 6 = 60문장 | 내 말로 바꾸기 → 오늘 누구에게 쓸지 약속 → 다음 날 확인 |
| 가 우리말 | 평소 잘 안 쓰지만 아름답고 정확한 우리말 (표준국어대사전 뜻 기준) | 10개 주제 × 6 = 60낱말 | 그 낱말로 내 문장 만들기 |
| あ 일본어 | 왕초보 생활 회화 + 히라가나·가타카나 글자표와 퀴즈 | 12개 장면 × 5 = 60표현 + 장면별 대화 | 역할 대화(상대 말 듣기 → 내 차례에 말하기) |
| A 영어 | 왕초보 생활 회화 | 12개 장면 × 5 = 60표현 + 장면별 대화 | 역할 대화 |

일본어·영어 장면: 인사 → 자기소개 → 카페 → 식당 → 길 묻기 → 쇼핑 → 교통 → 호텔 → 취미 → 약속 잡기 → 날씨와 안부 → 도움이 필요할 때.
12장면을 모두 완주하면 여행이나 일상에서 간단한 대화를 할 수 있도록 짰습니다.

모든 문장·예문·대화는 이 앱을 위해 새로 썼습니다(명언·교재 인용 없음).

## 하루 루틴 (학습 방법)

처음에 고른 과정마다 오늘의 루틴이 생기고, 하나를 끝내면 “다음: ○○”으로 이어집니다. 하나라도 끝내면 그날의 연속 기록이 이어집니다.

| 단계 | 하는 일 | 근거가 되는 원리 |
|---|---|---|
| 복습 | 빈칸을 보고 소리 내어 떠올린 뒤 확인 → 다시 / 헷갈림 / 기억남. 회화 표현은 익숙해지면(2단계부터) 빈칸 없이 한국어 뜻만 보고 통째로 말하기 | 인출 연습 · 간격 반복(1·2·4·7·15·30·60일) · 점점 어렵게 |
| 새로 배우기 | 문장: 피할 말과 비교 / 낱말: 뜻·예문·말맛 / 표현: 뜻·원문·읽기·한글 발음, 듣기·천천히 듣기 → 소리 내어 세 번 | 대비 학습 · 정교화 · 산출 효과(소리 내어 말하기) |
| 직접 써 보기 | 문장: 내 말로 바꾸기 + 실천 약속 / 낱말: 내 문장 만들기 / 회화: 장면 표현을 다 배운 날 역할 대화, 그 뒤로는 3일 넘게 쉰 장면을 대화로 복습 | 생성 효과 · 실행 의도 · 실제 상황 연습 |

- 하루 분량: 가볍게(문장 1 · 낱말 2 · 표현 3) / 보통 / 많이. 과정마다 하루 복습은 최대 8개.
- ‘다시’를 누른 것은 새 항목을 배운 뒤 한 번 더 나옵니다(바로 다시 보면 방금 본 답을 베끼게 되므로).
- 15일 간격까지 기억하면 ‘익힘’. 새벽 4시 전까지는 전날 루틴으로 칩니다.
- 듣기는 기기의 음성 합성(한국어·일본어·영어)을 씁니다. 기기에 해당 언어 음성이 없으면 알려 줍니다.

## 화면

- **오늘**: 이번 주 기록과 연속 일수, 과정별 오늘의 루틴과 진도(문장·낱말 수, 회화는 완주한 장면 수)
- **모음**: 과정별로 전체 보기 — 문장(상황·대상·검색·내 문장 추가·문장 속 단어), 우리말(주제·검색), 일본어·영어(장면별 표현과 대화 연습), 일본어 글자표·퀴즈
- **내 노트**: 내가 쓴 문장(바꿔 쓰기·내 문장 만들기), 실천 기록
- **설정**: 공부할 과정, 하루 분량, 좋은 문장의 대상, 한글 발음 보이기/숨기기, 아침 알림(매일 반복 캘린더 일정 파일), 화면 밝기, 백업 저장·불러오기, 초기화

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 앱 (빌드 없음) |
| `data.js` | 좋은 문장 (`window.AM_DATA`) |
| `data-uri.js` | 우리말 (`window.AM_URI`) |
| `data-ja.js` · `data-kana.js` | 일본어 회화 (`window.AM_JA`), 글자표 (`window.AM_KANA`) |
| `data-en.js` | 영어 회화 (`window.AM_EN`) |
| `sw.js` · `manifest.webmanifest` | 오프라인 지원, 홈 화면에 추가 |

콘텐츠를 고칠 때는 각 파일의 기존 카드 모양을 따르면 됩니다. `blank`(복습 때 가릴 부분)는 반드시 문장(`text` / `example` / `t`) 안에 글자 그대로 들어 있어야 합니다. 데이터 파일이 하나 빠져도 그 과정만 안 보이고 나머지는 동작합니다. 파일 목록을 바꾸면 `sw.js`의 `CACHE` 이름을 올립니다.

기록은 기기의 `localStorage`(`anything-morning.v1`)에만 저장됩니다. 1판(좋은 문장만 있던 때) 기록은 열 때 자동으로 옮겨집니다.

### 로컬에서 실행

```bash
cd anything-morning
python3 -m http.server 8765
# http://localhost:8765 열기
```

### 별도 사이트로 배포 (Netlify)

1. Netlify에서 **새 사이트**를 만들고 이 저장소를 연결합니다.
2. **Base directory**를 `anything-morning`으로 지정합니다. 빌드 명령과 게시 폴더는 이 폴더의 `netlify.toml`이 정합니다.
3. 배포가 끝나면 휴대폰에서 주소를 열고 “홈 화면에 추가”를 누릅니다.

나중에 완전히 다른 저장소로 옮겨도 이 폴더를 그대로 복사하면 됩니다.
