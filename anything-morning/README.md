# 애니띵 모닝 (Anything Morning)

하루 5분, 마음을 움직이는 문장 하나.
코치가 선수에게, 부모가 아이에게, 리더가 팀에게 — 사람을 설득하고 힘을 주는 **좋은 문장과 좋은 단어**를 매일 익히는 앱입니다.

PROCESS STUDIO와는 **별개의 앱**입니다. 이 폴더 안의 파일만으로 동작하며, PROCESS STUDIO 배포(`scripts/package-site.mjs`)에는 포함되지 않습니다.

## 하루 루틴 (학습 방법)

외우는 앱이 아니라 **실제로 말하게 만드는 앱**을 목표로, 효과가 잘 알려진 학습 원리를 순서대로 엮었습니다.

| 단계 | 하는 일 | 근거가 되는 원리 |
|---|---|---|
| 1. 어제 약속 확인 | “어제 ○○에게 써 봤나요?” → 써 봤으면 반응을 한 줄 기록 | 실천 확인 · 실제 사용 경험이 기억을 굳힘 |
| 2. 복습 | 상황과 ‘피할 말’을 보고 빈칸의 핵심 구절을 소리 내어 떠올린 뒤 확인 → 다시 / 헷갈림 / 기억남 | 인출 연습(꺼내 보기) · 간격 반복(1·2·4·7·15·30·60일) |
| 3. 오늘의 문장 | 흔히 하는 말 ✗ 과 좋은 말 ✓ 비교, ‘왜 마음이 움직일까’, 오늘의 단어, 소리 내어 세 번 읽기·듣기 | 대비 학습 · 정교화 · 소리 내어 읽기(산출 효과) |
| 4. 내 말로 바꾸기 | 내가 실제로 말할 사람과 상황, 내 말투로 다시 쓰기 | 생성 효과 |
| 5. 오늘의 실천 | 오늘 누구에게, 언제 쓸지 정하기 → 다음 날 아침 1단계에서 확인 | 실행 의도(언제·어디서·누구에게) |

- 하루 새 문장은 1개(설정에서 2~3개), 복습은 하루 최대 8개라 루틴이 5분 안에 끝납니다.
- ‘다시’를 누른 문장은 새 문장을 배운 뒤 한 번 더 나옵니다(바로 다시 보면 방금 본 답을 베끼게 되므로).
- 15일 간격까지 기억하면 ‘익힘’이 됩니다. 새벽 4시 전까지는 전날 루틴으로 칩니다.

## 콘텐츠

- **기본 문장 60개** (`data.js`): 10개 상황 × 6문장. 모두 이 앱을 위해 새로 쓴 오리지널 문장이라 저작권·출처 문제가 없습니다.
  - 상황: 동기 부여 · 실패 뒤에 · 피드백 · 인정과 칭찬 · 설득과 부탁 · 공감과 경청 · 갈등 풀기 · 믿음과 책임 · 감사와 사과 · 나에게 하는 말
  - 대상: 코치·선수, 리더·동료, 부모·자녀, 선생님·학생, 친구·연인, 나 자신 — 처음에 고른 대상의 문장부터 배웁니다.
  - 카드마다: 상황, 피할 말, 좋은 문장, 복습 때 가릴 핵심 구절, 왜 통하는지, 오늘의 단어(뜻·예문)
- **내 문장**: 책·경기·대화에서 만난 문장을 직접 추가하면 다음 날부터 복습에 나옵니다.

카드 모양은 `data.js` 맨 위의 주석과 기존 카드를 따르면 됩니다. `blank`는 반드시 `text` 안에 글자 그대로 들어 있어야 합니다.

## 화면

- **오늘**: 이번 주 기록, 연속 일수, 오늘의 루틴, ‘지금 필요한 말 찾기’(상황별 바로가기)
- **문장집**: 상황·대상·검색으로 찾기, 즐겨찾기, 학습에 추가, 메모, 내 문장 추가
- **단어장**: 문장에서 배운 단어 모음
- **내 노트**: 내가 바꿔 쓴 문장, 실천 기록(써 봤어요 / 아직)
- **설정**: 대상, 하루 새 문장 수, 아침 알림(매일 반복 캘린더 일정 파일), 화면 밝기, 백업 저장·불러오기, 초기화

## 기술

- 빌드 없는 정적 PWA: `index.html` · `styles.css` · `app.js` · `data.js` · `sw.js`(오프라인) · `manifest.webmanifest`
- 서버·계정 없음. 기록은 기기의 `localStorage`(`anything-morning.v1`)에만 저장되며, 설정의 백업 파일로 옮길 수 있습니다.
- 홈 화면에 추가하면 앱처럼 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다.

### 로컬에서 실행

```bash
cd anything-morning
python3 -m http.server 8765
# http://localhost:8765 열기
```

### 별도 사이트로 배포 (Netlify)

1. Netlify에서 **새 사이트**를 만들고 이 저장소를 연결합니다.
2. **Base directory**를 `anything-morning`으로 지정합니다. 빌드 명령과 게시 폴더는 이 폴더의 `netlify.toml`이 정합니다.
3. 배포가 끝나면 휴대폰에서 주소를 열고 “홈 화면에 추가”를 누릅니다.

나중에 완전히 다른 저장소로 옮겨도 이 폴더를 그대로 복사하면 됩니다.
